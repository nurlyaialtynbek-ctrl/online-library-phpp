# Онлайн кітапхана жүйесі (Online Library System)

Бұл жоба **PHP** және **MySQL (PDO)** технологияларын қолдана отырып әзірленген 8 апталық жеке жобалық тапсырма негізінде жасалған толыққанды веб-қосымша.

## Жобаның мақсаты
Оқырмандар мен әкімшілерге арналған кітап қорын басқару, іздеу, сүзу, санаттау және электронды түрде пікір қалдыру жүйесін құру.

## Негізгі мүмкіндіктер мен талаптардың орындалуы
- **Кемінде 3 бет:** Басты бет (`index.php`), Кіру/Тіркелу (`login.php`, `register.php`), Кітап қосу/өңдеу (`book_form.php`), Кітап беті (`book_detail.php`), Профиль (`profile.php`).
- **MySQL дерекқоры (4 кесте):** `users`, `categories`, `books`, `reviews`.
- **Аутентификация:** Тіркелу (`password_hash`), кіру (`password_verify`), сессиялар (`session_start`), шығу (`logout.php`) және жабық беттерді қорғау.
- **CRUD операциялары:** Кітаптарды қосу (Create), көру (Read), өңдеу (Update) және жою (Delete).
- **Іздеу, сүзу, сұрыптау және пагинация:** Атауы/авторы бойынша іздеу, жанр (санат) бойынша сүзу, жыл/атау бойынша сұрыптау, беттерге бөлу.
- **Қауіпсіздік:** SQL-инъекциядан қорғау (PDO Prepared Statements), XSS-шабуылдан қорғау (`htmlspecialchars`), жүктелетін мұқаба суреттерін (MIME-тип, өлшем) тексеру, рөлдерді бөлу (`user` / `admin`).

## Орнату және іске қосу нұсқаулығы
1. `database.sql` файлын phpMyAdmin немесе MySQL консолі арқылы импорттаңыз (`online_library` дерекқоры құрылады).
2. `config/db.php` файлындағы дерекқор параметрлерін (`$host`, `$dbname`, `$username`, `$password`) өз серверіңізге сәйкес баптаңыз.
3. Жобаны жергілікті серверге (XAMPP, OpenServer, Laragon) немесе хостингке (InfinityFree) орналастырып, браузерде ашыңыз.
