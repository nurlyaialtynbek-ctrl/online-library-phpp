# TaskFlow — Тапсырмалар менеджері (PHP & MySQL)

## Жоба сипаттамасы
**TaskFlow** — пайдаланушыларға күнделікті оқу, жұмыс және жеке тапсырмаларын жоспарлауға, санаттарға бөлуге, файлдар тіркеуге және мерзімдерін бақылауға арналған веб-қосымша.

## Негізгі функциялары
- Пайдаланушыларды тіркеу (`password_hash`) және сессия негізінде жүйеге кіру/шығу.
- Толық CRUD операциялары (тапсырма құру, оқу, өңдеу, жою).
- Кілтсөз бойынша іздеу, санат бойынша сүзу, мерзім бойынша сұрыптау және пагинация.
- Қауіпсіз файл жүктеу (`jpg, png, pdf, docx`, макс 2 МБ).
- Пайдаланушы профилі және статистика беті.
- SQL-инъекциядан (PDO Prepared Statements) және XSS шабуылдарынан (`htmlspecialchars`) қорғау.

## Орнату нұсқаулығы
1. Репозиторийді локальді сервердің (`htdocs` немесе `www`) қалтасына көшіріңіз.
2. `phpMyAdmin` арқылы `database.sql` файлын импорттаңыз.
3. `config/db.php` файлында дерекқор баптауларын тексеріңіз.
4. Браузерде `http://localhost/taskflow_project/index.php` мекенжайын ашыңыз.
